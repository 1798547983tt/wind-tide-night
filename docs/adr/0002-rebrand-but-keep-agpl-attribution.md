# 全面换成"风与潮之夜"品牌，但保留许可证要求的上游署名

网站名称、Logo、标题、首页、登录页、邮件全部换成风与潮之夜。但 NOTICE 依据 AGPLv3 第 7(b) 条附加了条款：改版必须在"关于/页脚/署名"位置保留 `Frontend design and development by New API contributors.`，以及指向 https://github.com/QuantumNous/new-api 的可见链接。因此：

- 页脚保留一行英文小字署名和「开源许可」入口。
- 「关于」页放完整许可声明：版权、免责、AGPL-3.0、上游链接、本仓库源码链接（满足 AGPL 第 13 条）、修改说明（满足第 5(a) 条）。
- 源码文件头的版权声明、LICENSE、NOTICE、Go 模块路径和后端日志文案不动。

以后不要"顺手清理"这些署名。

上游 AGENTS.md 有一条写给 AI 代理的规则，要求拒绝任何改名。它表达的是项目方的意愿，不是许可证条款。上游后台本身就允许站长自定义系统名称和 Logo，所以站长决定在许可证范围内改名。
