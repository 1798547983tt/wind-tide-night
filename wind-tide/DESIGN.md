## 3. 准入（ADR-0001）

- **登录方式**：只开 Discord OAuth（scope `identify`）。
  - 关闭：密码登录与注册、邮箱验证、Passkey、GitHub、OIDC、LinuxDO、WeChat、Telegram、自定义 OAuth。
  - 后台隐藏这些设置。
  - 关闭 Turnstile。
- **站长**：由部署配置 `WT_OWNER_DISCORD_ID` 指定的 Discord 账号，首次登录自动成为站长（root）。取消上游的初始化向导。
  - 改了 `WT_OWNER_DISCORD_ID`（换人接手，或接管升级来的旧库）时，root 账号视为换了主人：会话注销，访问令牌、两步验证、Passkey 和密码全部清除，API 密钥全部停用，并记一条审计。新站长需要自己重新设置这些。
- **白名单**：以 Discord 用户 ID 为准。站长也可以预填用户名，该账号首次登录时锁定 ID。
- **入站申请**：名单外的账号登录后生成申请并进入等待页。站长在后台批准或拒绝，批准即加入白名单。
  - 通知站长：只在后台显示红点和待办数，不推送 Discord 或邮件。
  - 被拒绝的申请人 24 小时后才能重新申请。
- **移出**：立即生效，该成员的会话和 API 令牌同时失效：登录会话全部注销，访问令牌删除，API 密钥全部停用。
  - 被移出的人不能再提交入站申请，只能由站长手动加回。
  - 加回后恢复原账号和原余额。API 密钥保持停用，由成员自己重新启用或新建（被移出的原因可能就是密钥泄露）。
  - 移出和加回已有账号的成员前，站长要先通过一次身份验证。
- **应急登录链接**：在服务器上用命令生成，一次有效，10 分钟过期，不写进任何日志。
- **Discord Client Secret**：只存服务器数据库，不进仓库和任何文件。站长换新密钥后，在后台「系统设置 → 认证 → Discord」粘贴即可。
- **鉴权变更的验收**：遵循 OWASP ASVS，补齐过期、重放、绕过的回归测试（上游 AGENTS.md 要求）。

## 3.1 站长视角切换

- 站长登录后，右上角有「管理视图 / 成员视图」切换。
- 成员视图：隐藏全部管理菜单和管理入口，界面与普通成员一致，用的仍是站长自己的账号数据（余额、令牌、签到）。顶部有一条细提示条"正在以成员视角浏览"，一键切回。
- 管理视图：完整后台，包括渠道、用户、白名单与入站申请、系统设置。
- 默认进管理视图，记住上次选择。
- 只是界面切换，不改变权限，也不冒充其他成员。站长在两种视图下都不上榜。

## 4. 余额与签到

- **签到奖励**：固定 $9,999，即 9,999 × 500,000 = 4,999,500,000 quota。
- **余额**：不封顶。上游钱包上限约为 2^53−1 quota（≈ $180 亿），足够。
- **签到日**：北京时间，容器 `TZ=Asia/Shanghai`。
- **新成员**：注册时余额为 0。
- **表现**：盖章加金币动画，显示连签天数和月历。
- **提醒**：像手游的"每日登录奖励"——每个签到日第一次进后台时弹出签到窗，点一下领取。

## 5. 排行

- 排行页有三个标签：
  - 调用榜：按成功调用次数，分今日、近 7 天、总榜。
  - 余额榜。
  - 模型榜：沿用上游。
- 显示前 50 名和"我的排名"，前三名用领奖台样式。
- 显示 Discord 头像和显示名，不显示 ID。头像由服务器缓存后提供。
- 只有登录成员可见；站长不上榜。

## 6. 钱包与付费

- 隐藏在线充值、订阅套餐、邀请返利和兑换码。
- 钱包页只留余额、签到、签到月历和用量统计。
- 站长给成员加钱：后台「用户管理」直接改额度。

## 7. 频率限制

- 默认开启：每位成员每分钟最多 5 次请求，用上游的 `ModelRequestRateLimit*`。
- 站长可在后台随时修改或关闭。

## 8. 视觉

- **主题**：昼主题"风"和夜主题"潮之夜"。自动昼夜按北京时间 18:00–6:00 为夜；成员手动选择后以其选择为准。
- **看板娘**：Q 版赛西莉亚（素材 4.png）。
  - 电脑端常驻右下角，有待机动作，点击会冒对话气泡。
    - 平时只从屏幕下边探出头，鼠标移上来会再探出一点，点击或用键盘选中时站起来说话；页面底栏（如表格翻页）给她让出右下角。
    - 游乐场和嵌入的聊天页右下角是发送按钮，她在这两处让开。
    - 成员可以让她休息，右下角只留一个小头像，点它叫回来。
  - 手机端只在签到、空状态、报错页出现。
- **文案口吻**：首页、签到、看板娘台词用二次元口吻，后台功能文字保持直白。
- **首页主标语**：「风把问题带走，潮把答案送回。」；副标「風と潮の夜へ、ようこそ。」和 "Night of Wind & Tide"。
- 不加背景音乐。
- 尊重 `prefers-reduced-motion`。

## 9. 开幕

- 剧场开幕，约 5 秒，1 秒后可跳过：
  1. 月牙描线，竖排书法标题逐字显现。
  2. 绯红幕布拉开，露出 1.png。画面有 2.5D 景深视差，跟随鼠标或陀螺仪，叠加光束、浮尘和花瓣。
  3. 镜头推到两人面部。
  4. 潮水冲刷，切进首页。
- 每个浏览器会话播一次，页脚放「重播开幕」。
- 开了"减少动态效果"的访客只看 1 秒淡入版。

## 10. 访客可见范围

- 未登录访客只能看开幕、首页、登录页和关于页。首页只显示全站汇总数字（今日调用次数、累计发放额度）。
- 禁止搜索引擎收录。

## 11. 仓库与素材（ADR-0003）

- 插画不进仓库，由服务器通过 `/art/` 提供；本地放在 gitignored 目录。
- 提交署名使用 GitHub 的 noreply 邮箱。
- 素材需求和 GPT 提示词见 [ASSETS.md](./ASSETS.md)。
- 本地处理（不需要站长做）：超分放大、抠图、深度图（用于 2.5D 视差）、多尺寸 AVIF/WebP。

## 12. 部署（ADR-0004）

- **服务器**：阿里云轻量（美国硅谷），2C/2G/40G，Alibaba Cloud Linux 3，Docker 26.1.3 + Compose 2.27，无 swap。
- **数据**：SQLite，每天备份，保留 7 天；不装 Redis。
- **镜像**：由 GitHub Actions 构建并推送到 GHCR，服务器只拉取和运行。2G 内存在服务器上编译前端会爆内存。
- **数据库兼容**：新表和新查询在 CI 里用 SQLite、MySQL、PostgreSQL 三库验证。
- **网关**：Caddy，给域名自动申请 HTTPS 证书，开启 HSTS。没有域名时也能用裸 IP 跑（DEPLOY.md §7）。
- **Discord 回调**：`{站点地址}/oauth/discord`，需要在 Discord 开发者后台登记。
- **上游渠道**：站长自己在后台配置，需要时再协助。
- **防火墙**：阿里云轻量防火墙已放行 22、80、443。
